# Image generation for WebWork

A reusable workflow for creating and editing images for any website or visual project.
Tool-agnostic, brand-agnostic, and usable independently of a website build.

Start with [the playbook](playbook.md). Fill in [the project brief](project-brief.template.md)
inside the target project, then use [the prompt library](prompt-library.md) for the actual assets.

| File | Use |
| --- | --- |
| [playbook.md](playbook.md) | Decisions, generation workflow, consistency, review and delivery |
| [project-brief.template.md](project-brief.template.md) | Project-specific art direction, asset list and output contract |
| [prompt-library.md](prompt-library.md) | Adaptable prompts for generation, edits and different asset types |
| [INTEGRATION.md](INTEGRATION.md) | Where this module fits into Claude's WebWork workflow |

This module expands [WebWork's media guide](../playbook/06-media.md). That guide governs website
delivery; this module covers producing the image and checking it before delivery. Hosting and
storage choices remain in [Media services](../stacks/media.md).

The method grew out of real-product photography, but its general rules are reference roles,
explicit constraints, repeatable art direction, controlled revisions and honest verification.
It does not carry over any particular brand's colors, models, framing grid or shot count.
