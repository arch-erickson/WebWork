# Before a page is called done

- [ ] Renders at 320, 390, 768, 1024, 1440, 1920 with no horizontal overflow
- [ ] Nothing important hidden behind a fixed header, menu open or closed
- [ ] Longest and shortest real content both look deliberate
- [ ] Words never sit over the subject of a photograph
- [ ] Contrast measured: 4.5:1 text, 3:1 large text and control edges
- [ ] Line length between 45 and 75 characters
- [ ] Keyboard reaches every control, in order, with a visible focus ring
- [ ] One h1, headings in order
- [ ] Every image has dimensions or a ratio, and alt text that says something
- [ ] First screen inside the weight budget
- [ ] Console clean, no failed requests, no third party the reader did not ask for
- [ ] Empty state written, not imagined
- [ ] Every repeated element came from the component module
