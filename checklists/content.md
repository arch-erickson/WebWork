# Content checklist

- [ ] Every item has what the publish gate requires, or it is not published
- [ ] Names and titles written for a stranger, not for the team
- [ ] No text addressed to the designer or the developer anywhere visible
- [ ] No placeholder copy left in a published page
- [ ] Prices, availability and dates match the source of truth
- [ ] Alt text describes what matters about the picture, not the file name
- [ ] Dates in a format the audience reads, and consistent everywhere
- [ ] One vocabulary for states: the same word for the same thing everywhere
- [ ] Legal pages written for this project rather than pasted from another
- [ ] Every outbound link works and goes where it claims
